# Getting Started



<figure><img src=".gitbook/assets/Screenshot 2025-06-27 093831.png" alt=""><figcaption></figcaption></figure>

Getting into DopeRaider is simple, whether you're a crypto native or new to Web3. We’ve designed the login so you can start playing in a few clicks — no complicated wallet setup required.

#### Login & Wallet (how it works)

DopeRaider uses an **in-app wallet** (powered by Thirdweb) so you can start fast. You can authenticate with:

* **Telegram**
* **Discord**

You can also connect via **WalletConnect** inside the app.

> Note: we intentionally keep onboarding simple — if you're new to Web3, you can start without doing any manual wallet setup.

Wallet & Network

* A wallet can be created for you automatically during login
* No separate wallet setup is required to start playing
* Current test chain: **Base Sepolia**
* Mainnet details will be shared closer to launch



Inventory & Stats

Your in-game **Inventory** displays:

* **Product Holdings** (weed, cocaine, etc.)
* **Consumables** (seeds, chemicals)
* **Upgrades** and their active durations
* **Respect** is your core progression stat
* **Trophies** earned achievements that show your status

Detailed inventory screens make it easy to track your assets, manage upgrades, and monitor your progression.



FAQs

**Do I need a wallet to play?**\
No. DopeRaider can create a secure in-app wallet for you during login.

**What network do I need?**\
For testing, DopeRaider uses **Base Sepolia**.

**How do I log in with Telegram?**\
Open the game from Telegram and complete the in-app login. Your Telegram identity is used for authentication, and a wallet can be created automatically during the process.

Getting started with DopeRaider is fast, flexible, and built to suit both Web3 newcomers and experienced players. Whether you're testing with us now or preparing for full launch, you're only a few clicks away from joining the underworld.
